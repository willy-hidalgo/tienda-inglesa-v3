# v12.9.11 — Sec23 Value residual selector-gap challenger

Diagnostic-only extension on top of the validated v12.9.10 productive baseline.

## Goal

Attack the remaining Value Sec23 selector gap without touching the productive forecast yet.
The challenger revisits only leaves that v12.9.10 still leaves on `v11_ses_rls` and asks
whether their own long-horizon closed-block history supports switching to the already-computed
v12 family.

## Causal gate

For each leaf, using only closed 28-day blocks:

- at least 8 eligible folds;
- win rate >= 75%;
- median gain > 0;
- p25 gain >= -0.5 pp;
- volume-weighted gain >= +0.5 pp;
- recent 3-block weighted gain >= 0;
- worst historical gain >= -10 pp;
- worst absolute-BIAS deterioration <= +5 pp;
- total target-period exposure capped at 10% of Sec23 Value volume;
- extra guards for top-5% and top-1% impact leaves.

The current OOS is never used to learn or authorize a switch.

## Temporal replay

Up to four pseudo-OOS cutoffs are replayed. At cutoff `b`, the gate is learned strictly
from blocks `b+1..N`; block `b+1` supplies the pseudo-current exposure profile and block `b`
is used only for evaluation.

## Production

No write-back is made to `valuehat` in v12.9.11. v12.9.10 remains the productive baseline.
Acceptance section 34 reports replay robustness and a current-OOS ACTIVE hypothetical.
