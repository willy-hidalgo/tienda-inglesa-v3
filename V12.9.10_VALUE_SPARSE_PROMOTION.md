# v12.9.10 — Value Sparse Rescue ACTIVE Promotion Gate

v12.9.10 promotes the v12.9.9 segmented Value sparse-demand rescue only when
an independent causal replay passes on the **official ACTIVE leaf cohort**.

The v12.9.9 segment/factor learner is unchanged: `07-09` / `10-13` positive
sales-day buckets, level method, seasonal flag, exact positive-day wMAPE and a
discrete factor grid capped at 1.15.

Promotion is section-level and uses only historical pseudo-OOS blocks. Current
OOS actuals are never used to decide whether the rescue is applied.

Default productive gate:

- 4 ACTIVE replay cutoffs;
- 100% winning cutoffs;
- median gain >= 0.25 pp;
- worst gain >= 0.00 pp;
- volume-weighted gain >= 0.25 pp;
- no deterioration in absolute BIAS;
- median selected ACTIVE volume <= 30%.

If the gate passes, the learned v12.9.9 factor is applied to `valuehat_raw` for
candidate leaves in both OOS and forecast-only. Quantity is unchanged. The
pre-rescue Value baseline is preserved in `v12910_valuehat_raw_before_sparse`
for exact counterfactual audit.

Acceptance report section 33 shows ACTIVE replay evidence and current OOS ACTIVE
impact. The latter is audit-only and does not affect the promotion decision.
