# v12.9.11 Dashboard toggle + sort + contrast fix

Dashboard-only hotfix. No model, forecast or statistical policy changes.

- Ranking metric period selector changed from select_slider to a compact toggle: OOS by default, In-sample when enabled.
- Cadence comparison moved immediately below the dashboard interpretation message and remains explicitly section-level.
- Ranking Styler changed from per-cell `set_properties` to lightweight global `set_table_styles`, preserving 13px font and pale-yellow SKU+Store background with substantially less browser styling payload.
- Numeric columns remain numeric so native ascending/descending sorting keeps numeric semantics.
- Main and non-active charts now use a light gray-blue actual area and a strong blue forecast line for higher visual contrast.
