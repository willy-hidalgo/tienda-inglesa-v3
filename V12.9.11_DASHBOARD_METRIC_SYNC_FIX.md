# v12.9.11 — Dashboard metric synchronization fix

Dashboard-only hotfix. No forecast/model changes.

- KPI order: In-sample first, OOS second.
- BIAS rendered as a compact green/red pill with up/down arrow.
- When Store+SKU is selected, the selected rows in Store and SKU rankings are forcibly synchronized to the exact leaf OOS metric from `metrics.parquet`.
- wMAPE and BIAS are algebraically verified from `sum_abs_error/sum_abs_y` and `sum_signed_error/sum_abs_y`; those sums are used if stale metric fields disagree.
- Equal `wMAPE == abs(BIAS)` is explicitly allowed and explained in the UI; this happens when all scored errors have one sign.
- Non-active chart marks section-specific start OOS and start forecast-only.
