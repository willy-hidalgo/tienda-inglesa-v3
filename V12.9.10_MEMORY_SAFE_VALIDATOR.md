# v12.9.10 — memory-safe validator hotfix

Operational hotfix only. Forecast logic, promotion gates, APP_VERSION and ARTIFACT_VERSION are unchanged.

`app.forecasting.validate_v12` no longer materializes the full forecast parquet. The structural validator now:

- reads the parquet schema lazily;
- validates required-column presence from schema only;
- projects only columns actually used by structural checks;
- pushes the SKU+store and OOS/forecast-only filters into `scan_parquet`;
- collects the reduced validation frame with the streaming engine;
- checks legacy period types with a separate lazy count;
- builds the final intervention/regime summary from a four-column lazy projection instead of re-reading the complete file.

This targets the Windows/Rust allocation failure observed on the ~565 MB, ~7.5M-row forecast artifact.
