# v12.9.11 — Dashboard ranking interaction/performance fix

Dashboard-only hotfix. El modelo y los forecasts permanecen sin cambios.

Cambios:
- Ranking SKU+Tienda visible = todas las hojas Active de sección+unidad, sin truncamiento.
- Pie de tabla con cantidad de SKU+Tienda Active y SKU únicos.
- Columnas numéricas de rankings conservan dtype numérico para sort asc/desc correcto.
- La selección visual ya no reordena automáticamente la fila seleccionada.
- Slider de período de métricas: OOS (default) / In-sample.
- Nuevo `metrics_in_sample.parquet` precalculado; la población Active sigue definida por OOS.
- Títulos de los tres rankings indican claramente el período activo.
- Selección de una fila SKU+Tienda sincroniza Tienda+SKU, gráfico, KPIs y rankings.
- Se elimina el control sidebar “Cómo generar 1d / 7d / 14d / 28d”.
- Hot path optimizado: carga de métricas limitada a sección+unidad con scan/streaming, ranking global vectorizado, comparación de cadencias bajo demanda y Excel generado solo cuando se solicita.

## Regeneración requerida

No recalcular forecasts. Regenerar artefactos de dashboard porque se añade `metrics_in_sample.parquet`:

```bash
uv run python -m app.dashboard_artifacts --all-update-blocks
```
